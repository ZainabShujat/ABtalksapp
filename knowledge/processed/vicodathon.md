# ViCodathon (Vibe Code Hackathon)

ViCodathon is ABTalks' branded vibe-coding hackathon, also referred to on the platform generically as the "Vibe Code Hackathon." Treat "Vibe Code Hackathon" as the recurring series name and "ViCodathon" as a specific branded edition of that series.

## ViCodathon 2026 (specific edition)

- Format: 48-hour hackathon
- Cost: free to enter
- Submission requirements: public GitHub repository, a live deployed URL, and an AI-usage log
- Status: historical/completed relative to the current project date (2026-08-10) — the official ViCodathon 2026 event notice places this event in the past

## Recurring series facts (apply across editions)

- 48-hour format
- Free to enter
- Public GitHub repo, live URL, and AI-usage log required per edition
- **Teams**: Participants can enter solo or in teams of up to 3 people. Duplicate team names are blocked.
- **Referrals & Attribution**: Hackathon referrals work via unique share-links (`?s=<slug>`), where the first touch wins and the referral is tracked.
- **Rejoining**: If a member is removed from a team by an admin or leader, they can rejoin without losing their original share-link attribution.
