# Website

abtalks.in is the program hub and community entry point. Current routes:

## Public (no login required)

- `/` — Home
- `/challenges` — 60-Day Coding Challenge overview
- `/claude-signup` — 60-Day Claude AI Challenge signup
- `/ai-cohort-register` — AI Cohort application (also `/apply`)
- `/ai-cohort-india` — AI Cohort application, India-specific version
- `/hackathon` — Vibe Code Hackathon landing page
- `/ai-workshop` — AI Tools Workshop microsite
- `/ai-workshop/events` — workshop event listing/dates
- `/login` — sign in

## Behind sign-in

- `/dashboard`, `/profile`, `/explore`, `/achievements` — participant hub
- `/challenge/today` — today's challenge task
- `/mission` — community/mission page
- `/marketplace` — redeem synergy points
- `/jobs` — jobs board
- `/program` — AI Cohort program area, once accepted
- `/talent` — recruiter/talent portal
- `/verify/[certificateId]` — certificate verification (public link, no
  login needed to view)

The website is presented as the program hub and community entry point; each
program also has its own dedicated topic file (see `programs.md` for the
index).
