# Website

abtalks.in is the program hub and community entry point. Route list below is
checked against the app's actual routes — use these exact paths when telling
someone where to go, and never invent a path.

## Public (no login required)

- `/` — Home
- `/challenges` — 60-Day Coding Challenge overview
- `/claude-signup` — 60-Day Claude AI Challenge signup
- `/ai-cohort-register` — AI Cohort application, US edition (`/apply` for the form)
- `/ai-cohort-india` — AI Cohort application, India edition (`/apply` for the form)
- `/hackathon` — Vibe Code Hackathon landing page (note: singular, there is
  no `/hackathons` page)
- `/ai-workshop` — AI Tools Workshop microsite
- `/ai-workshop/events` — workshop and event listing with dates
- `/program` — 31-Day AI Cohort public landing page
- `/hire/evidence` — evidence resume for a Scout match (there is no
  top-level `/evidence` page)
- `/contact` — contact page
- `/verify/[certificateId]` — public certificate verification, no login
- `/privacy`, `/terms`, `/cookies` — legal pages
- `/privacy/requests` — data request form
- `/talent/register`, `/talent/login` — recruiter portal signup and sign-in
- `/login` — sign in

## Behind sign-in

- `/dashboard`, `/profile`, `/explore` — participant hub
- `/achievements` — your certificates (see `certificates.md`)
- `/hire` — Scout, the recruiter entry point (sign-in required)
- `/challenge/today`, `/challenge/[day]` — daily challenge task
- `/claude/day/[day]` — Claude Challenge daily task
- `/quiz/[quizId]` — weekly quiz
- `/mission` — community/mission page
- `/marketplace` — redeem Synergy Points
- `/jobs` — jobs board
- `/register` — participant registration
- `/hackathon/register`, `/hackathon/dashboard`, `/hackathon/submission`
- `/program/apply`, `/program/assessment`, `/program/dashboard`,
  `/program/day/[day]`, `/program/curriculum`, `/program/videos`,
  `/program/leaderboard`, `/program/interview`,
  `/program/cohort-interview/[blueprint]` — AI Cohort program area
- `/talent/...` — recruiter/talent portal (approved recruiters)
- `/admin/...` — ABTalks staff only

Each program also has its own topic file: `coding-challenge.md`,
`claude-challenge.md`, `ai-cohort.md`, `hackathon.md`, `workshops.md`,
`certificates.md`, `hiring-and-recruiters.md`, `homepage.md`.
