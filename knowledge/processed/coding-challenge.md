# 60-Day Coding Challenge

The 60-Day Coding Challenge is a daily build challenge where participants choose a track and ship one real task every day for 60 days.

Tracks include:
- Software Engineering
- Data Science
- Artificial Intelligence

The challenge emphasizes a public portfolio, GitHub proof of work, and LinkedIn posting.

## Streaks and Submissions

- **Streaks**: A participant's current streak is based on making an on-time submission every day.
- **Late Submissions**: Submissions made late do not count towards the current streak.
- **Missing a day**: Missing a day completely resets the current streak to 0, but it does not remove the participant from the challenge. Participation continues, and they can start a new streak.
