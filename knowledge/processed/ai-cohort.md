# AI Cohort

The AI Cohort is a 31-day program for building and deploying a production-grade enterprise AI chatbot.

Core facts:
- 31 days end to end
- 8 gated phases
- Roughly 2–4 hours per day
- Free for participants
- Uses free tools such as Ollama, Groq, and Chroma

Coverage includes RAG, embeddings, agents, MCP, guardrails, Docker, Kubernetes, evaluation, and deployment.

## 8-phase / 31-day breakdown

| Phase | Days | Title | Focus |
|---|---|---|---|
| 1 | 1–3 | Env & Tooling | Local AI stack, Git, Ollama |
| 2 | 4–6 | Data | Coverage data & structured queries |
| 3 | 7–10 | Embeddings & Vector | Knowledge base + retrieval |
| 4 | 11–15 | LLM & Prompting | Prompting, fine-tune basics |
| 5 | 16–20 | App Build | Streamlit chatbot + FastAPI |
| 6 | 21–24 | Agentic + MCP | Tools, agents, MCP servers |
| 7 | 25–27 | Governance & Eval | Guardrails, evals, safety |
| 8 | 28–31 | Docker / K8s / Prod | Ship to production |

## Cohort flow

1. Apply — confirm laptop and GitHub setup.
2. 31 days of missions — build locally; GitHub artifacts verified.
3. AI interview — Upon completion, participants unlock a 15-minute real-time voice interview evaluated by AI.
4. Recruiter visibility — Recruiters use the Talent Portal (`/talent`) to view ranked participant profiles, which include their mission portfolios and interview summaries. Note: Participant phone numbers and entry details are never exposed to recruiters.

## Prerequisites

Python fundamentals, SQL & DB fundamentals, Git/GitHub/CLI, REST APIs &
backend basics, JavaScript & React fundamentals. Laptop with ≥8 GB RAM,
GitHub account. No paid API keys needed (Ollama / Groq / Chroma).
